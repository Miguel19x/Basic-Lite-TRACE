# Código de Conducta — Basic-Lite TRACE

**Proyecto:** Basic-Lite TRACE  
**Responsable:** Miguel19x (`miguelaranguren19x@outlook.com`)

---

## 1. Propósito

Este proyecto promueve un entorno técnico riguroso, respetuoso y orientado a la evidencia empírica reproducible. Toda participación en issues, discusiones técnicas, auditorías o comunicaciones relacionadas con **Basic-Lite TRACE** debe regirse por criterios de honestidad intelectual y trato profesional.

## 2. Conductas Esperadas

* **Rigor técnico y reproducibilidad:** Sustentar críticas, reportes de error o contrastes empíricos con datos, trazas reproducibles y especificaciones claras de entorno.
* **Respeto profesional:** Debatir ideas, implementaciones y métricas, nunca atacar a personas.
* **Respeto a la propiedad intelectual y la confidencialidad:** Cumplir los términos de [LICENSE.txt](LICENSE.txt), no publicar datos personales o confidenciales de terceros en canales públicos y respetar los canales privados definidos en [SECURITY.md](SECURITY.md).

## 3. Conductas Inaceptables

* Acoso, insultos, descalificaciones personales o discriminación de cualquier tipo.
* Publicación de información privada o confidencial (*doxxing*) de cualquier persona.
* Divulgación pública irresponsable de vulnerabilidades de seguridad antes de su notificación privada conforme a [SECURITY.md](SECURITY.md).
* Spam, promoción comercial no solicitada o uso del repositorio para distribuir contenido ilícito.

## 4. Aplicación y Contacto

El responsable del proyecto se reserva el derecho de moderar, editar o cerrar issues, comentarios o interacciones que contravengan este Código de Conducta.
